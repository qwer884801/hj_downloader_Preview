# hj_downloader_Preview

这是一个 Chrome Manifest V3 扩展，用于在浏览器已有登录状态下批量解析并保存资源。本文档只保留公开操作说明，所有站点、路径和资源标识均使用占位格式表示。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启 `开发者模式`。
3. 点击 `加载已解压的扩展程序`。
4. 选择本项目目录：`hj_downloader_Preview`。
5. 点击扩展图标，打开操作页面。

## 使用步骤

1. 在同一个 Chrome 用户配置中登录目标站点。
2. 打开扩展页面。
3. 点击 `选择根目录`，选择本地保存目录。
4. 在输入框中粘贴资源地址或资源 ID，每行一个。
5. 点击 `解析资源`，生成可检查的资源列表。
6. 勾选需要保存的资源。
7. 点击 `下载选中` 开始保存。

## 输入格式

公开说明中不要写真实站点，统一使用下面的占位格式：

```text
https://<target-domain>/<detail-path>?pid=<resource-id>
<resource-id>
https://<target-domain>/<list-path>/<user-id>
```

支持详情页地址、资源 ID，以及程序支持的列表页地址。混合粘贴时，程序会尽量整理为一行一个任务。

## 保存规则

- 文件会保存到用户在 Chrome 中选择的根目录。
- 默认遇到已存在文件时跳过。
- 默认文件名会包含标题、作者、资源 ID 和时长等信息。
- 批量任务默认先解析生成列表，再由用户确认勾选后下载。
- 如果站点登录状态失效，请先在浏览器中重新登录，再回到扩展页面继续操作。

- 不要提交开发日志、开发计划、调试记录或私人说明文档。
